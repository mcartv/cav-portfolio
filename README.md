# INDEX/ — CAV Portfolio

A creative developer portfolio mockup inspired by Swiss editorial design.

## Features

- Responsive Swiss-inspired editorial layout with oversized typography and restrained orange accents
- Animated entrance typography and reading progress bar
- 3D rotating development-project carousel with previous/next arrows, keyboard navigation, and swipe gestures
- About and technical toolkit sections
- Deliberately locked filmmaking archive with a stylized 404 error
- Contact footer

## Preview locally

This is a zero-build static frontend. Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/mcartv/cav-portfolio.git
cd cav-portfolio
```

Alternatively, use VS Code Live Server to preview and refresh after edits.

## Deploy

Import this repository into Vercel. Use the **Other** framework preset, no build command, and the repository root as the output directory. A static host such as GitHub Pages also works.

## Customize before publishing

The names, dates, project descriptions, project preview graphics, skills, email address, and LinkedIn link are placeholders for the mockup. Replace them with accurate details, images, and working project pages.

## Tech

Vanilla HTML, CSS, and JavaScript. Google Fonts is optional; the site falls back to local sans-serif fonts.
